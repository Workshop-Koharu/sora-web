# Sora Web Dashboard (sora.koharu.live)

Modern Obsidian Dark glassmorphism web dashboard for managing the **Sora (소라)** Discord bot across servers.

---

## 🌟 Features

- **Discord OAuth2 Login & Server Selector**: Manage any server where you have Administrator permissions.
- **Verification Management**: Configure Sendwich SMS, Resend Email, Captcha, and Button verification systems.
- **Points & Economy Tuning**: Configure attendance rewards, transfers, gambling parameters, and lottery pool settings.
- **Wiki & Knowledge Base**: Manage community wiki pages and version histories.
- **Ticket System Controls**: Set ticket categories, staff roles, and naming formats.
- **Privacy & Terms Policy Hub**: Clear separation of SMS/Phone and Email privacy policies, terms of service, and user consent documentation.

---

## 🚀 Tech Stack

- **Framework**: Next.js 14 (App Router) + React 18 + TypeScript
- **Styling**: Tailwind CSS + Lucide React + Glassmorphism Dark UI
- **Deployment**: Vercel ready (`sora.koharu.live`)

---

## 📦 Setup & Development

```bash
# Install dependencies
npm install

# Setup environment variables
cp .env.example .env.local

# Run development server
npm run dev
```
